= Access Control Matrix
:toc:

This matrix covers one workflow: *submitting a health-assessment request and viewing its status*, as described in link:architecture.adoc#_identity_and_access[architecture.adoc, Identity and access].
The approach is attribute-based, with roles for staff. For citizens and delegates, access depends on ownership of the request and on a current delegation. Staff roles are not part of this workflow.

Identifiers follow link:identity_model.adoc[identity_model.adoc]. "Owner" means the Citizen ID stored on the request.

== Audit

Every decision in this matrix, whether allowed or denied, creates an audit event in the Audit Store. It records the actor's Citizen ID or service name, the action, the Request ID, the time, and the outcome.
For delegated actions, the event also records the grantor's Citizen ID and the delegation ID.
