= Architecture Decision Records

Use one file per important architecture decision, based on link:ADR-0001-template.adoc[ADR-0001-template.adoc].

Naming: `ADR-nnnn-<short-title>.adoc`, numbered sequentially. Accepted ADRs are not rewritten; a changed decision is recorded in a new ADR that supersedes the old one.

Each ADR should state context, decision, alternatives, consequences, and follow-up actions.
