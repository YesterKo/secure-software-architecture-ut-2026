== Export procedure

. Start Structurizr in local mode (the successor of Structurizr Lite) from the repository root:
+
[source,powershell]
----
docker run -it --rm -p 8080:8080 -v "${PWD}\diagrams:/usr/local/structurizr" structurizr/structurizr local
----
+
On macOS/Linux, use `-v "$(pwd)/diagrams:/usr/local/structurizr"` instead.
. Open http://localhost:8080, open each view, and adjust the layout in the diagram editor if needed. Layout changes are saved automatically to `workspace.json`.
. Export each view as PNG and save it as `c4-context.png` or `c4-container.png` in this directory.
. Commit the DSL, `workspace.json`, and the PNGs together.
